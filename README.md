# A-rosa'je

## Installation

### Prerequisites
- A working internet connection
- Flutter SDK installed and configured
- Android toolchain installed and configured

### Steps

```bash
$ git clone https://github.com/MSPR-Plantes-2024/mobile-app.git
cd app-pharmacie
$ flutter pub get
$ flutter build apk
```

Get the APK from `build/app/outputs/flutter-apk/app-release.apk`

Install it on your device(s)
